## Cross-reference to the existing game

- `src/main.ts` builds the tracked robot and reusable course meshes. The visible robot now uses yellow protective track guards, dark belts, pale exposed end wheels, and an open bay with generic visual packages.
- `src/drivePhysics.ts` owns the deterministic differential-drive force model. It separates per-track motor requests from traction limits and computes downhill gravity along the ground tangent.
- Geometry proxies are intentionally simplified for stable browser physics. The photographs do not justify exact internal mechanical dimensions or electronic specifications, so those remain generic and are not presented as facts about the physical robot.

## Older reference assets

The earlier user-provided black tracked-robot image remains a supplementary silhouette reference only. Its all-black exterior is not applied over the newer photographs' yellow guards. The generated arena/obstacle reference sheet is used for general modular event-arena styling, not as a flattened environment texture or source of measured geometry.
